What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of websites and web pages.

Your First HTML Page

<!DOCTYPE html>
<html>
<head>
  <title>My First Website</title>
</head>
<body>
  <h1>Hello World!</h1>
</body>
</html>
