Learn Python step by step from beginner to advanced beginner.

🐍 Python Lesson 1: Hello World

Python can display text using print().


name = "LearnHub"
print(name)

🐍 Python Lesson 2: Variables

A variable stores information.


name = "Tshepiso"
age = 29

print(name)
print(age)

🐍 Python Lesson 3: Numbers and Calculations

Python can perform calculations.


a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)

🐍 Python Lesson 4: If Statements

An if statement tells Python to run code when a condition is true. 


age = 20

if age >= 18:
    print("You are an adult")

🐍 Python Lesson 5: Functions

A function is a block of code that performs a specific task. 


def hello():
    print("Hello Tshepiso! 🐍")
    print("Welcome to LearnHub!")

hello()

🐍 Python Lesson 6: Lists

A list stores multiple items in one variable. 


fruits = ["Apple", "Banana", "Orange"]

print(fruits)
print(fruits[0])

🐍 Python Lesson 7: For Loops

A loop allows Python to repeat code. 


fruits = ["Apple", "Banana", "Orange"]

for fruit in fruits:
    print(fruit)

🐍 Python Lesson 8: While Loops

A while loop repeats code while a condition is true. 


number = 1

while number <= 5:
    print(number)
    number = number + 1

🐍 Python Lesson 9: User Input

Python can ask the user for information using input(). 


name = input("What is your name? ")

print("Hello " + name)

🐍 Python Lesson 10: Dictionaries

A dictionary stores information using keys and values. 


student = {
    "name": "Tshepiso",
    "course": "Python",
    "level": "Beginner"
}

print(student["name"])
print(student["course"])

🐍 Python Lesson 11: Functions with Parameters

A function can receive information called a parameter. 


def greet(name):
    print("Hello " + name)

greet("Tshepiso")

🐍 Python Lesson 12: Mini Project

Now we combine variables, conditions and functions. 


def check_age(age):

    if age >= 18:
        print("You are an adult.")
    else:
        print("You are under 18.")

check_age(20)
